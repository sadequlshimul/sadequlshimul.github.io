# Jabirs Weg – সাইটের ফাইল-কাঠামো

প্রতিটা সেকশনের কোড আলাদা ফাইলে। কোনো একটা সেকশনে কাজ করতে হলে শুধু সেই ফাইল বদলালেই হবে।

## কোন কাজে কোন ফাইল

| কী বদলাতে চাও | ফাইল |
|---|---|
| হোমের অপশন-কার্ড (নাম, রঙ, ক্রম)। প্রতিটা ট্যাপ করলে নতুন পেজ খোলে | `js/home.js` |
| "তোমার লক্ষ্য" পেজ | `js/goal.js` (পেজের জায়গা: `index.html`-এর `id="goal"` সেকশন) |
| "সকল কোর্স" পেজ, কোর্স পেজ, বুকিং ফর্ম | `js/courses.js` |
| পেমেন্ট বক্স, কাউন্টডাউন, প্রমাণ জমা | `js/payment.js` |
| কার্ড/টিকিটের ছবি ও অবস্থা (বাকি / যাচাই / নিশ্চিত) | `js/ticket.js` |
| আমার ব্যাচ পেজ | `js/my.js` |
| মক টেস্ট পেজ | `js/mock.js` |
| ভোকাবুলারির ডিজাইন | `js/vocab.js` |
| **ভোকাবুলারির শব্দ** | `data/vocab-a1.json`, `vocab-a2.json`, `vocab-b1.json` |
| অ্যাডমিন (ওভারভিউ, বুকিং, কোর্স) | `js/admin.js` |
| অ্যাডমিনের পেমেন্ট মেলাও | `js/admin-match.js` |
| সবার সাধারণ ডিজাইন (রঙ, ফন্ট, কার্ড) | `css/base.css` |
| পেজের কাঠামো (হিরো, ফুটার, প্রতিটা পেজের জায়গা) | `index.html` |
| Supabase সংযোগ, সাধারণ ছোট ফাংশন | `js/core.js` |
| ডেটাবেসের SQL | `sql/` |

`js/boot.js` সবশেষে চলে, সাধারণত ছুঁতে হয় না।

## নতুন পেজ যোগ করতে চাইলে
1. `index.html`-এ নতুন সেকশন ও হিরোর শিরোনাম (`hXxx`) যোগ করো।
2. `js/core.js`-এর `PG`-তে পেজের নাম যোগ করো।
3. `js/home.js`-এ কার্ড ও `PAGE`-এ নাম যোগ করো।

## ফাইল লোডের নিয়ম
- সাধারণ ফাইল (core, courses, goal, ticket, payment, my, home, boot) পেজ খুলতেই লোড হয়।
- `mock.js`, `vocab.js` শুধু ওই পেজ খুললে লোড হয়, আর `admin.js`, `admin-match.js` শুধু `#admin`-এ গেলে। তাই সাধারণ ছাত্রের সাইট হালকা থাকে।

## আপলোড (GitHub)
1. পুরো ফোল্ডারটা যেমন আছে তেমন আপলোড করো (`index.html`, `css`, `js`, `data`, `sql`)।
2. **`config.js` আলাদা**: তোর আসল `config.js` (Supabase URL ও key) আগের জায়গায় যেমন আছে তেমনই রাখো। এই ZIP-এ সেটা নেই। নমুনা `config.example.js`।
3. কোনো ফাইল বদলালে ব্রাউজারে পুরনোটা দেখাতে পারে। তাই `index.html`-এ ওই ফাইলের শেষে `?v=1` বদলে `?v=2` করো। দরকার মতো লোড হওয়া ফাইলগুলোর (mock, vocab, admin) জন্য `index.html`-এর `window.JW_V='1'` বদলে `'2'` করো।

## ভোকাবুলারির শব্দ যোগ বা বদল (কোড ছাড়া)
`data/vocab-a1.json` খুলে প্রতিটা শব্দ এভাবে লেখা:
```
{ "a": "der", "w": "Tisch", "bn": "টেবিল", "p": "ডার টিশ" }
```
- `a` = আর্টিকেল (`der` / `die` / `das`), `w` = জার্মান শব্দ, `bn` = বাংলা অর্থ, `p` = বাংলায় উচ্চারণ।
- চাইলে `"pl": "Tische"` (বহুবচন) আর `"ex": "Der Tisch ist groß."` (উদাহরণ বাক্য) যোগ করতে পারো, নিজে থেকে দেখাবে।
- প্রতিটা `{ ... }`-এর পরে কমা, শেষটার পরে কমা নয়।
- নতুন লেভেল (যেমন B2): `data/vocab-b2.json` বানাও, আর `data/vocab-index.json`-এ নাম যোগ করো: `["A1","A2","B1","B2"]`।
